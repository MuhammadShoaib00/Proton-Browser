# 🔄 Auto-Update Setup Guide — Step-by-Step

This guide will help you set up automatic updates for Proton Browser. You have **two options**:

1. **GitHub Releases** (Recommended — Free, Easy, Reliable)
2. **Custom Server** (Your Own Website)

---

## 📋 Option 1: GitHub Releases (Recommended)

### ✅ Advantages
- ✅ **Free** — No hosting costs
- ✅ **Reliable** — GitHub's CDN is fast worldwide
- ✅ **Automatic** — `electron-builder` publishes releases automatically
- ✅ **Secure** — GitHub signs releases automatically

### 📝 Step-by-Step Setup

#### **Step 1: Create a GitHub Repository**

1. Go to [github.com](https://github.com) and sign in
2. Click **"New repository"** (or the **+** icon → New repository)
3. Name it: `proton-browser` (or any name you prefer)
4. Set it to **Public** (required for free auto-updates)
5. Click **"Create repository"**

#### **Step 2: Get a GitHub Personal Access Token**

1. Go to: **Settings** → **Developer settings** → **Personal access tokens** → **Tokens (classic)**
2. Click **"Generate new token (classic)"**
3. Name it: `Proton Browser Auto-Updater`
4. Select scopes:
   - ✅ `repo` (Full control of private repositories)
   - ✅ `write:packages` (if you want to publish packages)
5. Click **"Generate token"**
6. **⚠️ COPY THE TOKEN NOW** — you won't see it again!
7. Save it somewhere safe (password manager, text file, etc.)

#### **Step 3: Configure Your Code**

1. Open `main.js` and find these lines (around line 756):
   ```javascript
   const UPDATER_GITHUB_OWNER = 'YOUR_GITHUB_USERNAME';
   const UPDATER_GITHUB_REPO  = 'proton-browser';
   ```

2. Replace `YOUR_GITHUB_USERNAME` with your actual GitHub username:
   ```javascript
   const UPDATER_GITHUB_OWNER = 'your-actual-username';  // ← Your GitHub username
   const UPDATER_GITHUB_REPO  = 'proton-browser';          // ← Your repo name
   ```

3. Open `package.json` and update the `publish` section (around line 42):
   ```json
   "publish": {
     "provider": "github",
     "owner": "your-actual-username",  // ← Your GitHub username
     "repo": "proton-browser"           // ← Your repo name
   }
   ```

#### **Step 4: Set Up Environment Variable for Token**

**Windows (PowerShell):**
```powershell
# Set token (replace YOUR_TOKEN with your actual token)
$env:GH_TOKEN = "YOUR_TOKEN"

# Or set it permanently (run as Administrator):
[System.Environment]::SetEnvironmentVariable("GH_TOKEN", "YOUR_TOKEN", "User")
```

**Windows (Command Prompt):**
```cmd
setx GH_TOKEN "YOUR_TOKEN"
```

**macOS/Linux:**
```bash
export GH_TOKEN="YOUR_TOKEN"
# Or add to ~/.bashrc or ~/.zshrc:
echo 'export GH_TOKEN="YOUR_TOKEN"' >> ~/.bashrc
```

#### **Step 5: Build and Publish Your First Release**

1. **Update version** in `package.json`:
   ```json
   "version": "1.0.1"  // ← Increment from 1.0.0
   ```

2. **Build and publish**:
   ```bash
   npm run publish:github
   ```

   This will:
   - Build the installer
   - Create a GitHub release
   - Upload the installer as a release asset
   - Generate `latest.yml` (update manifest)

3. **Verify** on GitHub:
   - Go to your repo → **Releases**
   - You should see **v1.0.1** with the installer attached

#### **Step 6: Test Auto-Update**

1. **Install the old version** (1.0.0) on a test machine
2. **Open the app** → Settings → About → **"Check for Updates"**
3. It should detect version 1.0.1 and prompt to download
4. After download, click **"Restart Now"** to install

#### **Step 7: Future Updates**

Every time you want to release an update:

1. **Update version** in `package.json`:
   ```json
   "version": "1.0.2"  // ← Increment
   ```

2. **Build and publish**:
   ```bash
   npm run publish:github
   ```

3. **Users will automatically get notified** when they:
   - Open the app (checks after 10 seconds)
   - Click "Check for Updates" in Settings
   - Every 4 hours (automatic background check)

## 🌐 Option 2: Custom Server (Your Own Website)

If you prefer to host updates on your own website instead of GitHub:

### ✅ Advantages
- ✅ **Full control** — Your own domain
- ✅ **Custom branding** — Your website, your style
- ✅ **No GitHub dependency**

### ⚠️ Requirements
- A web server (Apache, Nginx, or any static hosting)
- HTTPS (required for security)
- Ability to upload files

### 📝 Step-by-Step Setup

#### **Step 1: Create Update Endpoint**

Create a file on your server: `https://yourwebsite.com/updates/latest.yml`

The file should look like this:
```yaml
version: 1.0.1
files:
  - url: Proton-Browser-Setup-1.0.1.exe
    sha512: abc123...  # ← Generated by electron-builder
    size: 12345678
path: Proton-Browser-Setup-1.0.1.exe
sha512: abc123...
releaseDate: '2025-02-18T12:00:00.000Z'
```

#### **Step 2: Upload Installer**

Upload your installer to: `https://yourwebsite.com/updates/Proton-Browser-Setup-1.0.1.exe`

#### **Step 3: Configure Code**

1. Open `main.js` and replace the GitHub updater config (around line 773):
   ```javascript
   // Remove GitHub config:
   // autoUpdater.setFeedURL({ provider: 'github', ... });

   // Add custom server:
   autoUpdater.setFeedURL({
     provider: 'generic',
     url: 'https://yourwebsite.com/updates/'
   });
   ```

2. Update `package.json` `publish` section:
   ```json
   "publish": {
     "provider": "generic",
     "url": "https://yourwebsite.com/updates/"
   }
   ```

#### **Step 4: Build and Deploy**

1. Build the installer:
   ```bash
   npm run build:win
   ```

2. Copy files to your server:
   - `dist/Proton-Browser-Setup-1.0.1.exe` → `updates/Proton-Browser-Setup-1.0.1.exe`
   - `dist/latest.yml` → `updates/latest.yml`

3. Ensure HTTPS is enabled (required by Electron)

## 🔧 Troubleshooting

### ❌ "Update Error 404"
- **Cause**: GitHub username/repo not configured correctly
- **Fix**: Double-check `UPDATER_GITHUB_OWNER` and `UPDATER_GITHUB_REPO` in `main.js`

### ❌ "Cannot find module electron-updater"
- **Cause**: Missing dependency
- **Fix**: Run `npm install`

### ❌ "Authentication failed"
- **Cause**: `GH_TOKEN` not set or invalid
- **Fix**: Regenerate token and set `GH_TOKEN` environment variable

### ❌ Updates not downloading
- **Cause**: Firewall or network blocking GitHub
- **Fix**: Check internet connection, allow Electron through firewall

### ❌ "Update available" but nothing happens
- **Cause**: `autoDownload` is set to `false` (user must click "Download")
- **Fix**: This is intentional — user must approve downloads for security

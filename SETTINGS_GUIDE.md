# ⚙️ INDUS Browser - Settings Guide

## 🎯 Accessing Settings

### Method 1: Menu Button
1. Click the **⋮** (three dots) button in the top-right corner
2. Select **"Settings"** from the dropdown menu

### Method 2: Keyboard Shortcut (Coming Soon)
- Press `Ctrl+,` to open settings directly

---

## 📋 Settings Categories

### 1. 🔧 General Settings

**Home Page**
- Set your default home page URL
- Opens when you create a new tab
- Default: https://www.google.com

**Search Engine**
- Choose your preferred search engine:
  - Google (default)
  - Bing
  - DuckDuckGo
  - Yahoo

**Restore Tabs on Startup**
- Toggle to restore your previous browsing session
- Reopens all tabs from last session

---

### 2. 🎨 Appearance

**Theme**
- Dark (Professional Blue) - Current theme
- Light - Coming soon
- System Default - Matches your OS

**Zoom Level**
- Adjust page zoom from 50% to 200%
- Use +/- buttons or slider
- Default: 100%

**Show Bookmarks Bar**
- Toggle bookmarks bar visibility
- Coming soon feature

**Smooth Scrolling**
- Enable/disable smooth scrolling animations
- Enabled by default

---

### 3. 🔒 Privacy & Security

**Screenshot Protection**
- Status: Always Active
- Cannot be disabled (core feature)
- Protects from all screen capture tools

**Ad Blocker**
- Toggle built-in ad blocking
- Blocks ads and trackers
- Enabled by default for faster browsing

**Do Not Track**
- Sends "Do Not Track" requests to websites
- Asks websites not to track you
- Enabled by default

**Clear Browsing Data**
- Remove cookies, cache, and history
- Click "Clear Data" button
- Confirmation required

---

### 4. ⚡ Performance

**Hardware Acceleration**
- Status: Always Enabled
- Uses GPU for faster rendering
- Cannot be disabled (optimized for performance)

**Preload Pages**
- Predicts and preloads pages you might visit
- Faster navigation
- Enabled by default

**Lazy Load Images**
- Loads images only when needed
- Saves bandwidth
- Enabled by default

---

### 5. 🔬 Advanced

**Developer Tools**
- Toggle developer tools access
- Press F12 when enabled
- For advanced users

**User Agent**
- View your browser identification string
- Read-only field
- Shows: "INDUSBrowser/1.0"

**Reset to Defaults**
- Restore all settings to default values
- Requires confirmation
- Cannot be undone

## 🆘 Troubleshooting

### Settings Won't Open?
- Check browser console (F12)
- Restart browser
- Clear cache and try again

### Settings Not Saving?
- Check file permissions
- Ensure not in read-only mode
- Try reset to defaults

### Menu Not Showing?
- Click the ⋮ button again
- Check if menu is hidden behind window
- Restart browser

## ⚡ Quick Icon Setup (1 Minute)

### Step 1: Generate the Icon

Run this command:
```bash
generate-icon.bat
```

Or manually open:
```bash
create-icon.html
```

### Step 2: Save the Icon

1. A browser window will open with the icon generator
2. The 256x256 icon will be displayed automatically
3. **Right-click** on the canvas
4. Select **"Save Image As..."**
5. Save as: `assets\logo.png`

### Step 3: Launch INDUS Browser

```bash
npm start
```

That's it! Your icon will now appear everywhere! 🎉

## 💡 Pro Tips

1. **Icon Quality**: Use the 256x256 PNG for best quality
2. **SVG Fallback**: Browser uses SVG if PNG not found
3. **Restart Required**: After adding PNG, restart browser
4. **Taskbar Update**: May need to re-pin to taskbar

## 🔄 Update Icon Later

To change the icon in the future:

1. Edit `assets/logo.svg` with your design
2. Run `generate-icon.bat` again
3. Save new `logo.png`
4. Restart browser

## 🆘 Need Help?

### Icon Not Showing?
1. Check file exists: `dir assets\logo.png`
2. File size should be ~50-100KB
3. Restart browser completely
4. Try: `npm start`

### Generator Not Working?
1. Open `create-icon.html` manually
2. Use online converter: https://svgtopng.com
3. Upload `logo.svg`, download as PNG

### Build Issues?
1. Run: `npm install`
2. Run: `npm run rebuild`
3. Run: `npm start`

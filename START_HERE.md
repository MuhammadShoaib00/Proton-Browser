## 🐛 Troubleshooting

### Browser Won't Start?

```bash
npm install
npm run rebuild
npm start
```

### Icon Not Showing?

See: `FIX_ICON.md`

Quick fix:
```bash
npm start
```

(Icon should show using SVG)

### Screenshot Protection Not Working?

1. Check Windows version: `winver` (need Build 17134+)
2. Rebuild: `npm run rebuild`
3. Restart: `npm start`
